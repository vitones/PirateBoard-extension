# Segurança

Se você achou uma falha de segurança na extensão ou no PirateBoard, **não abra uma issue pública**. Use o formulário do site:

<https://pirateboard.veetones.workers.dev/denunciar>

Escolha o motivo **"Falha de segurança"**, descreva o problema com passos para reproduzir e, se quiser resposta, deixe um contato. Não é preciso informar gamertag. Não inclua dados pessoais de terceiros.

Respondemos o mais rápido possível e agradecemos o aviso responsável.

## O que a extensão guarda

Apenas no `chrome.storage.local` do seu navegador: a última leitura (números e chaves de companhia) e o código de edição do seu perfil. Nada disso é enviado a terceiros.
